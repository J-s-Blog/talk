数据库初始化说明

首次使用前，请登录 Supabase Dashboard，进入项目的 SQL Editor，执行以下 SQL 以创建必要的表与安全策略：

-- 用户表（仅存用户名与密码哈希，不存明文密码） create table if not exists public.mylist_users ( id uuid primary key default gen_random_uuid(), username text unique not null, pwd_hash text not null, salt text not null, created_at timestamptz default now() ); -- 任务表（task_date 明文用于按日期筛选；其余字段加密） create table if not exists public.mylist_tasks ( id uuid primary key default gen_random_uuid(), username text not null, task_date date not null, encrypted_data text not null, created_at timestamptz default now(), updated_at timestamptz default now() ); create index if not exists idx_mylist_tasks_user_date on public.mylist_tasks(username, task_date); -- 分类表 create table if not exists public.mylist_categories ( id uuid primary key default gen_random_uuid(), username text not null, encrypted_name text not null, created_at timestamptz default now() ); -- 启用行级安全（RLS） alter table public.mylist_users enable row level security; alter table public.mylist_tasks enable row level security; alter table public.mylist_categories enable row level security; -- 允许 anon 角色访问（数据本身已加密，服务器无法解密） create policy "mylist all" on public.mylist_users for all to anon, authenticated using (true) with check (true); create policy "mylist tasks all" on public.mylist_tasks for all to anon, authenticated using (true) with check (true); create policy "mylist cats all" on public.mylist_categories for all to anon, authenticated using (true) with check (true);

执行完成后，刷新此页面即可正常注册与登录。

安全提示：本工具采用端到端加密，密码不传输到服务器，任务内容使用您的密码派生的密钥进行 AES-GCM 加密。即使数据库泄露，他人也无法读取您的任务内容。但请务必妥善保管密码——密码遗失后历史数据将无法解密。
